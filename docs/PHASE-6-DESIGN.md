# تصميم المرحلة 6 — الكتالوج والتحليلات الخفيفة

## الهدف

تضيف هذه المرحلة واجهة كتالوج عامة في جذر GitHub Pages، وتحوّل بيانات المنتجات الملتزمة إلى `catalog.json` و`index.html` بصورة حتمية، وتضيف عدّاد زيارات خفيفًا لكل منتج وصفحة الكتالوج دون حساب أو مفتاح أو خدمة استضافة جديدة.

## مصدر الحقيقة

يقرأ `automation/build_catalog.py` مسارات HTML الملتزمة تحت `products/` وبيانات `ideas/backlog.json`. يطابق `built_period` مع المنتج الأسبوعي، ويستخدم عنوان الصفحة ووصفها عند عدم توفر سجل backlog مطابق. ينتج الكتالوج روابط داخلية فقط، وبطاقات تتضمن العنوان والوصف والفترة والتصنيف.

## التحليلات

يستخدم المصنع بكسل CounterAPI العام الموثق رسميًا، بصيغة `https://counterapi.com/pixel.gif` مع `ns` و`action=view` و`key` ثابتين لكل صفحة. الموقع الرسمي يذكر أن الخدمة مجانية وعامة ولا تتطلب حسابًا أو مفتاحًا أو مصادقة، مع حد يومي مرن معلن قدره 100,000 طلب [1]. ويذكر أيضًا إخفاء البيانات الشخصية في صورة hashes غير قابلة للتتبع [1].

يُحقن البكسل بواسطة `automation/instrument_analytics.py` بعد اجتياز المرشح بوابة LLM الأساسية. لا يستطيع كود LLM اختيار عنوان التحليلات أو إدخاله. وتقبل البوابات فقط المضيف والمسار والاستعلام المحدد في `automation/analytics_policy.py`; أي رابط أو script أو stylesheet أو API شبكي آخر يبقى مرفوضًا.

## سير التنفيذ

في مسار Tier A، يُبنى المنتج ثم يمر بالفحص الأصلي، ويُحقن البكسل، ثم يمر بالفحص النهائي، ثم يُبنى الكتالوج ويُفحص ثابتًا وبالمتصفح قبل commit واحد يضم backlog والمنتج والكتالوج.

في مسار LLM، يُولد المرشح ويمر أولًا بالبوابات الصارمة دون تحليلات. بعد قبول المزود، يُحقن البكسل الموثوق، ثم تُعاد بوابة HTML وبوابة Chromium في وضع allowlist، ثم يُبنى الكتالوج ويُفحص قبل النشر. عند فشل المزود أو استخدام fallback، لا يتغير ترتيب السلسلة ولا تُعلن رسالة غير صادقة.

## معايير القبول

تُقبل المرحلة بعد تحقق جميع الشروط التالية: وجود كتالوج يذكر كل المنتجات الملتزمة؛ وجود بكسل واحد معتمد لكل صفحة منشورة؛ نجاح بوابات HTML وChromium للمنتجات والكتالوج؛ تشغيل GitHub Actions حقيقي ينشر منتجًا جديدًا ويحدث الكتالوج؛ عودة صفحة الكتالوج والمنتج بحالة HTTP 200؛ تحقق تفاعل المتصفح من الروابط والمنتج؛ ونجاح Telegram برسالة تحتوي رابط المنتج والكتالوج. لا تبدأ المرحلة 7 قبل توثيق هذه النتائج.
